# Katalon Studio structure

- **Test Cases** — Katalon test case files (.tc); main test logic
- **Keywords** — Custom keyword scripts (Groovy); reusable test utilities
- **Object Repository** — UI object locators and identifiers
- **Test Suites** — Collections of test cases grouped by feature/flow
- **Test Listeners** — Setup/teardown hooks for test lifecycle
- **Data Files** — Test data (Excel, CSV) for data-driven testing
- **Reports** — Test execution output and HTML reports
- **Scripts** — Helper Groovy/Java scripts; keywords and libraries
- **Profiles** — Test environment configurations (dev/staging/prod URLs, credentials)
